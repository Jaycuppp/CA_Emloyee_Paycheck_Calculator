## 🚀 Overview
The **CA Employee Paycheck Calculator** is a standalone desktop application designed to provide California-based hourly employees with net-pay projections.


## 🛠️ Key Technical Features
* **Custom GUI Engine:** Built using **Tkinter** with a focus on input validation (preventing non-numerical errors) and a clean, user-friendly interface.
* **Financial Logic Accuracy:** Implements California-specific tax logic, separating taxable vs. non-taxable income streams for accurate net-pay reporting.
* **Standalone Distribution:** Packaged using **PyInstaller** and **InstallForge** to create a professional `.exe` installer, handling all dependency bundling for the end-user.
* **Data Privacy:** 100% local execution; no financial data is transmitted over the network, ensuring complete user confidentiality.

## 🏗️ Technical Stack
* **Language:** Python 3.x
* **GUI Framework:** Tkinter
* **Packaging Tools:** PyInstaller, InstallForge
* **Platform:** Windows OS
